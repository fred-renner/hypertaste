# The taste-habit catalogue

The smith's reading list only. Names the taste habits a world might exercise (e.g. quit a dead
vein, scout before committing, manage belief under a tight budget) so the ship-gate can ask
"does this world exercise a habit the catalogue names?".

This is in the smith's diet, never the player's: everything the player sees is re-expressed
through the flat tool surface first, so the catalogue's labels never reach it (the leak wall,
DESIGN.md).

STATUS: drawn, empty. Entries are added as LOOP 2 is built and habits are named.
